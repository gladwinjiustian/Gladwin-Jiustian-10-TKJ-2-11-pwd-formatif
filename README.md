# Website Portofolio Pribadi - Pemrograman Web Dasar

Proyek Asesmen Formatif Praktik CSS (TP 4 & TP 5) Siswa: Gladwin Jiustian - Kelas X TKJ 2 SMK Kristen Immanuel Pontianak.

## Struktur Proyek

* index.html : Halaman utama portal portofolio.
* components/ : Komponen UI terisolasi (button-set, card, card-badge, navbar, sidebar, interactive).
* pages/ : Halaman-halaman web lengkap (profile, about, contact, gallery, hero).
* styles/ : Kumpulan file stylesheet eksternal (.css).
* assets/ : Gambar, foto, dan aset media pendukung proyek.
